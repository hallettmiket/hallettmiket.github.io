🔧murmurent machines

A six-second announcement. murmurent machines load asks every machine you can reach (this computer, the lab's servers, its clusters) at the same time and prints one table: cores and GPUs busy of total, who is on it; murmurent machines usage does the same for each storage tier. In a Claude Code session, /murmurent-machines shows that table as it is. The guide: docs/machines.md. All the training videos: mikehallett.science/assets/videos.
